# Prototype-1 Frontend

The frontend is built with React, TypeScript and Vite. It provides the interface for user accounts, document uploads, encryption options and file transfers.

## Requirements

- Node.js 18 or later
- npm

## Install and Run

From this folder, run:

```bash
npm install
npm run dev
```

Vite will print the local address in the terminal. Open that address in a browser. Make sure the backend is running before using features that send API requests.

## Build

To create a production build, run:

```bash
npm run build
```
